## 🚀 Featured Projects

### 🎬 [MovieMate — Content-Based Movie Recommender](https://github.com/hanzla-anjum016/movie-recommender)
Recommends movies by content similarity (plot, genre, keywords) across 186K+ titles using TF-IDF, SVD, and FAISS for fast nearest-neighbor search. Includes a live search-as-you-type interface built to stay responsive at that scale.
**[Live Demo](https://moviematerecommender.streamlit.app/)**

### 🎭 Sentiment Analyzer with Explainability
A movie review sentiment classifier (89% accuracy) that doesn't just predict — it shows *why*, highlighting which words pushed each prediction toward positive or negative. Deployed as a FastAPI backend with a Streamlit frontend.
**[Live Demo](https://sentimentanalysissite.streamlit.app/)** · **[API Docs](https://setimentanalyzer.up.railway.app/docs)**

### 🛡️ VeriSafe — Phishing URL Detector
A Random Forest classifier for phishing URL detection, benchmarked against HistGradient Boosting and LightGBM, achieving 99.67% accuracy on the PhiUSIIL dataset.
